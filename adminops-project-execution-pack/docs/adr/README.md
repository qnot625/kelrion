# Architecture Decision Records

Use an ADR for decisions that materially affect architecture, security boundaries, data ownership, deployment, app count or long-term maintenance.

## Status values

- Proposed
- Accepted
- Superseded
- Rejected

## Template

```markdown
# ADR-NNN: Decision title

- Status: Proposed
- Date: YYYY-MM-DD
- Owners: ...

## Context
## Decision
## Consequences
## Alternatives considered
## Security/privacy implications
## Rollback or superseding condition
```
